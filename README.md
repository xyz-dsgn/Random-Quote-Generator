Программа для генерации случайных цитат

## Описание программы 
GUI-приложение на Python, которое генерирует случайные цитаты из предопределённого списка. Пользователь может фильтровать цитаты по автору и теме, а также просматривать историю сгенерированных цитат, которая сохраняется в JSON-файл.
## Требования для запуска 
Что нужно установить на компьютер: - Python 3.10 или выше - Библиотеки: `pip install tkinter`
## Как запустить 
```bash 
git clone https://github.com/xyz-dsgn/Random-Quote-Generator
cd Random-Quote-Generator
python main.py
```
## Как пользоваться
1. Запустите скрипт.
2. Нажмите кнопку «Сгенерировать цитату» для получения случайной цитаты.
3. Используйте поля «Автор» и «Тема», чтобы отфильтровать цитаты.
4. История отображается в списке ниже.
5. Историю можно сохранять и загружать при запуске.
## Пример работы 
1. Запустите приложение — появится окно с кнопкой «Сгенерировать цитату», полями для фильтрации по автору и теме, а также списком истории.
2. Введите, например, в поле «Автор» фамилию «Иванов» и нажмите «Применить фильтр».
3. Теперь при нажатии «Сгенерировать цитату» будет показана случайная цитата Алексея Иванова, например:
`«Будь лучше, чем вчера». — Алексей Иванов (Мотивация).`
4. Сгенерированная цитата появится в списке истории.
5. Если фильтр не дал результатов (например, вы ввели несуществующего автора), появится сообщение: `«Нет цитат для отображения после фильтрации».`
6. При повторном запуске программы история сохраняется и отображается автоматически.
